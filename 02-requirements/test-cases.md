
# Test Cases

## TC-007 — განაცხადის წარმატებით გაგზავნა

**Test Scenario:**  
განაცხადის წარმატებით გაგზავნის შემოწმება

**Preconditions:**  
მომხმარებელი დარეგისტრირებულია, შესულია საკუთარ ანგარიშში, პროფილი სრულად აქვს შევსებული და ხელმისაწვდომია სასურველი ვაკანსია.

**Test Steps:**
1. მომხმარებელი გადადის ვაკანსიების გვერდზე.
2. ირჩევს სასურველ სტაჟირებას.
3. ათვალიერებს ვაკანსიის დეტალებს.
4. აჭერს „განაცხადის გაგზავნა“ ღილაკს.

**Test Data:**
- ვაკანსია: Junior Software Tester
- სფერო: IT

**Expected Result:**  
განაცხადი წარმატებით უნდა გაიგზავნოს და მომხმარებელს უნდა გამოუჩნდეს შეტყობინება: „თქვენი განაცხადი გაგზავნილია.“

**Actual Result:**  
განაცხადი წარმატებით გაიგზავნა და გამოჩნდა შეტყობინება: „თქვენი განაცხადი გაგზავნილია.“

**Status:**  
Pass
