# CareerStart


CareerStart არის კარიერული პლატფორმის კონცეფცია, რომელიც შექმნილია სტუდენტებისა და დამწყები პროფესიონალებისთვის.

პლატფორმის მიზანია მომხმარებელს დაეხმაროს შესაბამისი Internship და Junior პოზიციების პოვნაში, პროფილისა და CV-ის შექმნაში და სასურველ ვაკანსიაზე მარტივად განაცხადის გაგზავნაში.

---

## 🎯 პროდუქტის იდეა

CareerStart განკუთვნილია სტუდენტებისა და დამწყები პროფესიონალებისთვის, რომლებსაც სურთ საკუთარ სფეროში პირველი პროფესიული გამოცდილების მიღება ან კარიერის ახალ სფეროში დაწყება.

პლატფორმა ფოკუსირებულია Internship და Junior პოზიციებზე და მომხმარებელს ეხმარება არა მხოლოდ ვაკანსიის პოვნაში, არამედ კარიერული განვითარების მიმართულების განსაზღვრაში.

---

## ❗ პრობლემა

სტუდენტებსა და დამწყებ პროფესიონალებს ხშირად აქვთ შემდეგი პრობლემები:

- შესაბამისი სტაჟირების პოვნა რთულია;
- არ იციან, საიდან დაიწყონ კარიერული განვითარება;
- არ იციან, რა უნარები სჭირდებათ სასურველი პოზიციისთვის;
- უჭირთ ეფექტური CV-ის შექმნა და საკუთარ გამოცდილებაზე მორგება;
- შესაბამისი ვაკანსიები სხვადასხვა პლატფორმაზეა გაფანტული;
- ხშირად არ აქვთ პროფესიული გამოცდილება და Network.

### ძლიერი მხარეები

- პროფესიონალებთან დაკავშირების შესაძლებლობა;

- ვაკანსიების დიდი რაოდენობა.

### შეზღუდვა

პლატფორმა ძალიან ფართოა და დამწყები მომხმარებლისთვის მხოლოდ Internship და Junior შესაძლებლობების პოვნა შეიძლება რთული იყოს.

### რას სთავაზობს?

- სხვადასხვა სფეროს ვაკანსიებს;

- სფეროსა და კატეგორიის მიხედვით ფილტრაციას.

### ძლიერი მხარეები

- ვაკანსიების დიდი რაოდენობა;

- ძიებისა და ფილტრაციის შესაძლებლობა.

ვაკანსიების დიდი რაოდენობის გამო დამწყები მომხმარებლისთვის შესაბამისი Internship ან Junior პოზიციის პოვნა შეიძლება რთული იყოს.

### CareerStart-ის უპირატესობა

- სტაჟიორებს (Interns);
- Junior კანდიდატებს.
