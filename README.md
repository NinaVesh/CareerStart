# CareerStart


CareerStart არის კარიერული პლატფორმის კონცეფცია, რომელიც შექმნილია სტუდენტებისა და დამწყები პროფესიონალებისთვის.

პლატფორმის მიზანია მომხმარებელს დაეხმაროს შესაბამისი Internship და Junior პოზიციების პოვნაში, პროფილისა და CV-ის შექმნაში და სასურველ ვაკანსიაზე მარტივად განაცხადის გაგზავნაში.

---

## 🎯 პროდუქტის იდეა

CareerStart განკუთვნილია სტუდენტებისა და დამწყები პროფესიონალებისთვის, რომლებსაც სურთ საკუთარ სფეროში პირველი პროფესიული გამოცდილების მიღება ან კარიერის ახალ სფეროში დაწყება.

პლატფორმა ფოკუსირებულია Internship და Junior პოზიციებზე და მომხმარებელს ეხმარება არა მხოლოდ ვაკანსიის პოვნაში, არამედ კარიერული განვითარების მიმართულების განსაზღვრაში.

---

## ❗ პრობლემა

სტუდენტებსა და დამწყებ პროფესიონალებს ხშირად აქვთ შემდეგი პრობლემები:

- შესაბამისი სტაჟირების პოვნა რთულია;
- არ იციან, საიდან დაიწყონ კარიერული განვითარება;
- არ იციან, რა უნარები სჭირდებათ სასურველი პოზიციისთვის;
- უჭირთ ეფექტური CV-ის შექმნა და საკუთარ გამოცდილებაზე მორგება;
- შესაბამისი ვაკანსიები სხვადასხვა პლატფორმაზეა გაფანტული;
- ხშირად არ აქვთ პროფესიული გამოცდილება და Network.

# 📋 Product Requirements

## FR-01 — რეგისტრაცია

მომხმარებელს უნდა შეეძლოს ანგარიშის შექმნა Email-ისა და პაროლის ან Google ანგარიშის გამოყენებით.

### Acceptance Criteria

- ვალიდური Email და პაროლი → ანგარიში წარმატებით იქმნება;
- არასწორი Email → გამოჩნდება Error Message;
- არასწორი პაროლი → გამოჩნდება Error Message;
- უკვე რეგისტრირებული Email → ანგარიში არ შეიქმნება და გამოჩნდება Error Message;
- ცარიელი Required ველები → ანგარიში არ შეიქმნება და გამოჩნდება შესაბამისი Error Message.

---

## FR-02 — პროფილის შექმნა და რედაქტირება

მომხმარებელს უნდა შეეძლოს საკუთარი პროფილის შექმნა, ინფორმაციის შენახვა და შემდგომში მისი რედაქტირება.

### Required ინფორმაცია

- სახელი
- გვარი
- Email
- ტელეფონის ნომერი
- სასურველი სფერო
- ენები

### Optional ინფორმაცია

- უნივერსიტეტი
- პროექტები
- Soft Skills
- Hard Skills
- სამუშაო გამოცდილება
- Portfolio / LinkedIn / GitHub

### Acceptance Criteria

- ყველა Required ველის შევსების შემთხვევაში → პროფილი წარმატებით შეიქმნება;
- Required ველის გამოტოვების შემთხვევაში → გამოჩნდება Error Message;
- მომხმარებელს უნდა შეეძლოს პროფილის რედაქტირება;
- განახლებული ინფორმაცია წარმატებით უნდა შეინახოს სისტემამ.

---

## FR-03 — ვაკანსიების ძიება და ფილტრაცია

მომხმარებელს უნდა შეეძლოს ვაკანსიების მოძიება და გაფილტვრა სფეროსა და გამოცდილების დონის მიხედვით.

### Acceptance Criteria

- ფილტრის გარეშე → გამოჩნდება ყველა ხელმისაწვდომი ვაკანსია;
- Internship ფილტრის არჩევისას → გამოჩნდება მხოლოდ შესაბამისი სტაჟირებები;
- შესაბამისი ვაკანსიის არარსებობის შემთხვევაში → გამოჩნდება შეტყობინება;
- ფილტრის გაუქმებისას → გამოჩნდება ხელმისაწვდომი ვაკანსიები.

---

## FR-04 — ვაკანსიაზე განაცხადის გაგზავნა

მომხმარებელს უნდა შეეძლოს სასურველ ვაკანსიაზე განაცხადის გაგზავნა საკუთარი პროფილისა და CV-ის გამოყენებით.

### Acceptance Criteria

- შევსებული პროფილი და CV → განაცხადი წარმატებით იგზავნება;
- აუცილებელი ინფორმაციის არქონის შემთხვევაში → განაცხადი არ იგზავნება;
- წარმატებული გაგზავნის შემდეგ → მომხმარებელი იღებს დადასტურების შეტყობინებას;
- მომხმარებელს არ უნდა შეეძლოს ერთსა და იმავე ვაკანსიაზე განმეორებითი განაცხადის გაგზავნა.

---

## FR-05 — ვაკანსიების რეკომენდაცია

სისტემამ მომხმარებლის ინტერესის სფეროს, უნარებისა და გამოცდილების დონის მიხედვით უნდა შესთავაზოს შესაბამისი ვაკანსიები.

### Acceptance Criteria

- შესაბამისი პროფილის შემთხვევაში → მომხმარებელს ეჩვენება შესაბამისი ვაკანსიები;
- რამდენიმე შესაბამისი ვაკანსიის არსებობის შემთხვევაში → გამოჩნდება რამდენიმე რეკომენდაცია;
- შესაბამისი ვაკანსიის არარსებობის შემთხვევაში → სისტემა არ აჩვენებს არარელევანტურ რეკომენდაციებს;
- პროფილის განახლების შემთხვევაში → რეკომენდაციები განახლდება.
- სტაჟიორებს (Interns);
- Junior კანდიდატებს.

# 🎯 MVP — პირველი ვერსია

CareerStart-ის პირველი ვერსიის მიზანია მომხმარებელმა შეძლოს:

**რეგისტრაცია → პროფილის შექმნა → ვაკანსიის პოვნა → ფილტრაცია → განაცხადის გაგზავნა.**

### MVP ფუნქციები

- რეგისტრაცია / Login;
- პროფილის შექმნა და რედაქტირება;
- CV-ის შექმნა;
- ვაკანსიების მოძიება;
- ვაკანსიების ფილტრაცია;
- კომპანიების მიერ ვაკანსიის დამატება;
- ვაკანსიაზე განაცხადის გაგზავნა;
- განაცხადის სტატუსის ნახვა.

# 🧭 User Journey

CareerStart-ის მომხმარებლის ძირითადი გზა:

1. მომხმარებელი შედის CareerStart-ის პლატფორმაზე;
2. რეგისტრირდება Email-ით ან Google ანგარიშით;
3. ქმნის საკუთარ პროფილს;
4. ავსებს საჭირო ინფორმაციას და ამატებს Skills-სა და პროექტებს;
5. ქმნის ან ამატებს CV-ს;
6. ეძებს სასურველ Internship ან Junior ვაკანსიას;
7. ფილტრავს ვაკანსიებს სფეროსა და გამოცდილების დონის მიხედვით;
8. ათვალიერებს ვაკანსიის დეტალებს;
9. აგზავნის განაცხადს საკუთარი პროფილისა და CV-ის გამოყენებით;
10. იღებს განაცხადის გაგზავნის დამადასტურებელ შეტყობინებას;
11. აკვირდება განაცხადის სტატუსს.

---

## 📩 განაცხადის სტატუსები

მომხმარებლის განაცხადს შეიძლება ჰქონდეს შემდეგი სტატუსები:

- **განაცხადი გაგზავნილია**
- **კანდიდატურა განხილვის პროცესშია**
- **გიწვევთ ინტერვიუზე კანდიდატურის განსახილველად**
- **სამწუხაროდ, ამ ეტაპზე თქვენი კანდიდატურა უარყოფილია**

---

# 🗺️ Product Roadmap

CareerStart-ის განვითარება დაგეგმილია ეტაპობრივად, რათა პირველ ეტაპზე შეიქმნას პროდუქტის ძირითადი ფუნქციონალი, შემდეგ კი დაემატოს პერსონალიზებული და კარიერული განვითარების ფუნქციები.

## 🔴 Phase 1 — MVP

პირველ ეტაპზე მომხმარებელს უნდა შეეძლოს ძირითადი კარიერული პროცესის გავლა:

**რეგისტრაცია → პროფილის შექმნა → CV → ვაკანსიის ძიება → ფილტრაცია → განაცხადის გაგზავნა**

### ფუნქციები

- რეგისტრაცია / Login;
- პროფილის შექმნა და რედაქტირება;
- CV-ის შექმნა;
- ვაკანსიების ძიება;
- ვაკანსიების ფილტრაცია;
- კომპანიების მიერ ვაკანსიის დამატება;
- ვაკანსიაზე განაცხადის გაგზავნა;
- განაცხადის სტატუსის ნახვა.

---

## 🟠 Phase 2 — Personalization

მეორე ეტაპზე პლატფორმა უფრო პერსონალიზებული გახდება.

### ფუნქციები

- Job Matching;
- პერსონალიზებული ვაკანსიების რეკომენდაციები;
- Skills Assessment;
- მომხმარებლის Skills-ის მიხედვით შესაბამისი შესაძლებლობების შეთავაზება.

### მიზანი

მომხმარებელმა ნაკლები დრო დახარჯოს ვაკანსიების ძიებაზე და მიიღოს მის პროფილზე მორგებული შესაძლებლობები.

---

## 🟢 Phase 3 — Career Development

მესამე ეტაპზე პლატფორმა განვითარდება კარიერული განვითარების მიმართულებით.

### ფუნქციები

- Career Blogs;
- Career Guides;
- Career Roadmaps;
- რეკომენდაციები Skills-ის განვითარებისთვის;
- სხვადასხვა პროფესიის შესახებ საგანმანათლებლო რესურსები.

### მიზანი

CareerStart დაეხმაროს მომხმარებელს არა მხოლოდ სამსახურის პოვნაში, არამედ პროფესიულ განვითარებასა და კარიერული გზის დაგეგმვაში.

---

# 💡 Product Vision

CareerStart-ის გრძელვადიანი მიზანია გახდეს პლატფორმა, რომელიც მომხმარებელს დაეხმარება კარიერული გზის სხვადასხვა ეტაპზე.
